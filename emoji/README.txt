Emoji image files are served from here at /emoji/<tier>/<file>.

Drop your collection folders in here so they render in the app:
  emoji/common/    emoji/rare/    emoji/legendary/    emoji/mythic/
(these are the tier folders from solace-emoji.zip)

special/talisman.png is a PLACEHOLDER for the death-shield talisman —
replace it with real art whenever you have it.

This folder is gitignored (except this README + special/) — the images
live on the server, not in the repo.
